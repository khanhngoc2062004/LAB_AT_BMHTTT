# Paper Replication Demo Guide

## 1. Research Paper

Title: Software security in practice: knowledge and motivation

DOI: 10.1093/cybsec/tyaf005

## 2. Demo Objective

Demonstrate a qualitative coding workflow
using synthetic developer interview statements.

## 3. Dataset

File: data/raw/interviews.csv

8 synthetic interview statements.

## 4. Analysis Process

Step 1: Open Coding
Assign an initial code to each statement.

Step 2: Axial Coding
Group related codes into categories.

Step 3: Selective Coding
Identify a central theme.

Step 4: Knowledge Taxonomy
Classify knowledge acquisition activities.

Step 5: Motivation Analysis
Classify motivations and barriers.

## 5. Run Demo

Command:

./scripts/run_demo.sh

Expected results:

Interview statements: 8
Open codes: 8
Axial categories: 3

The script also displays knowledge taxonomy,
motivation categories, and validation results.

## 6. Limitations

The dataset is synthetic.

Coding was performed manually.

The script summarizes and validates existing codes.

This is a methodological demonstration,
not an empirical replication of the paper.
